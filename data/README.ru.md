# Почасовые температуры сухого термометра в Астане

[English](README.md) · [Қазақша](README.kk.md) · Русский · [简体中文](README.zh.md)

Эталонный расчёт использует файл **KAZ_AKM_Astana.351880_TMYx.2011-2025.epw**, распространяемый Climate.OneBuilding. Ряды *Development of Global Typical Meteorological Years (TMYx)* составили Linda K. Lawrie и Drury B. Crawley. По описанию издателя типичный год собирается из почасовых данных метеостанций, а для других переменных EPW привлекаются дополнительные метеоданные. Для этого расчёта извлекается только температура сухого термометра. [Издатель и авторство](https://climate.onebuilding.org/) · [Методика TMYx](https://climate.onebuilding.org/sources/default.html)

Исходные годы месяцев с января по декабрь: **2015, 2021, 2014, 2017, 2017, 2022, 2018, 2019, 2013, 2020, 2015 и 2014**. На отдельных границах месяцев исходный год меняется. Так получается типичный год из 8 760 часов, составленный из характерных месяцев разных лет. По флагам исходного файла нельзя установить, что каждое почасовое значение получено отдельным наблюдением.

Подготовленный CSV содержит исходный год, месяц, день, час EPW и температуру сухого термометра в °C. Эти поля выбраны из исходного EPW и записаны в компактном формате CSV. Значения температуры сохраняют исходную точность, без интерполяции, сглаживания и дополнительного округления. Проектные таблицы и остальные метеопараметры из исходного ZIP для данной модели не нужны. Сведения об источнике относятся как к CSV, так и к встроенным результатам. ## Проверка и повторное извлечение данных

Запустите любую из команд ниже из каталога проекта. В режиме загрузки проверяются хеши архива и EPW. В режиме чтения локального файла для отдельного сценария также можно указать другой полный почасовой EPW невисокосного года. Для другого места или версии используйте отдельное выходное имя.

```bash
python weather.py --download --output regenerated.csv
python weather.py --epw KAZ_AKM_Astana.351880_TMYx.2011-2025.epw --output local_extract.csv
```

Программа отклоняет пропущенные, повторяющиеся и переставленные часы, неполные годы, неконечные температуры и значения сухого термометра вне допустимого диапазона поля EPW. Численные расчёты и результаты панели хранятся отдельно от входного метеорологического ряда.

## Воспроизведение семисуточной модели SnowCool

В `snowcool_replay.csv` записаны результаты моделирования при эталонном и ухудшенном контакте из *Astana SnowCool — Physics-Guided Design of Seasonal Snow Storage for Data-Center Cooling in Astana*, проверенная версия 1.1 от 16 сентября 2026 года. Заданные 120 суток хранения и семь суток тепловой нагрузки образуют численный эталон зависимости доступной почасовой холодопроизводительности от запаса льда.

В исходной модели задан кубический объём 50 м³ с теплоизоляцией 300 мм, 400 кг ледового эквивалента на м³ и выдержкой 120 суток. Цель — поддерживать 5 кВт в течение 168 часов. Исходный расчёт использует скрытую теплоту плавления 334 кДж/кг и конечный резерв 10 %. В отдельном сценарии для дата-центра и сравнении июльских запасов в трёх хранилищах принято 333,5 кДж/кг. [Feistel, энтальпия плавления льда при 0 °C](https://www.teos-10.org/pubs/Feistel_2003.pdf)

Выборка построена из `data/timeseries_reference.csv` и `data/timeseries_degraded.csv` внутри `Astana_SnowCool_Audited_LaTeX_and_Code.zip`, SHA-256 архива `5b33c423ff76f28aafc10041d25765d17c9466d1140867bbe70826f76f08bf70`. Скрипт проверяет хеши обоих CSV и файла JSON с энергетическим балансом, по которому пересчитывается запас льда. Мощность за час — среднее по 16 равным интервалам длиной 3,75 минуты. Энергия льда в конце часа равна доле оставшегося льда, умноженной на начальный запас скрытой теплоты исходного варианта (1 855,5556 кВт·ч). Нулевой час показывает состояние сразу после хранения, для него нет средних по интервалам. Значения сохраняются с шестью десятичными знаками. В варианте ухудшенного контакта интеграл резервного охлаждения по часам равен 8,156 кВт·ч, остаток скрытой теплоты в конце — 322,014 кВт·ч. В исходном исследовании отдельный расчёт с меньшим шагом для проверки сходимости дал 8,166 кВт·ч резервного охлаждения. Оба значения при округлении дают 8,2 кВт·ч. Если исходный архив доступен, воспроизведите выборку командой

```bash
python snow_inputs.py /path/to/Astana_SnowCool_Audited_LaTeX_and_Code.zip
```

В расчёте объёмы уплотнённого снега составляют примерно 55 м³ для контейнера с теплоизоляционной оболочкой, 60 м³ для хранилища из теплоизоляционных панелей и 50 м³ для укрытого бурта с подстилающей изоляцией. Для контейнера предусмотрена циркуляция талой воды. Два других варианта иллюстрируют пассивное хранение. Июльский запас рассчитывается с учётом заданного пользователем среднего теплопритока в каждое хранилище за 91 день. Исследования снега и охлаждения работают на данных, включённых в проект. См. также [региональные метеостанции](regions/README.ru.md).
