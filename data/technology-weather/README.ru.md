# Почасовая влажность, давление и солнечная радиация

[English](README.md) · [Қазақша](README.kk.md) · Русский · [简体中文](README.zh.md)

Почасовые ряды температур сухого термометра по городам дополнены данными в 21 файле CSV со сжатием gzip. В каждом 8 760 строк в исходном порядке EPW, от первого часа 1 января до 24-го часа 31 декабря по местному стандартному времени файла. В реестре станций даны ссылки на исходные ZIP коллекции Climate.OneBuilding TMYx, составленной Linda K. Lawrie и Drury B. Crawley. Указаны источник метеоданных, фактический период исходных лет, координаты, смещение времени и хеши SHA-256 каждого архива, EPW и температурного CSV. [Реестр станций](../regions/stations.json) · [Описание станций и исходные файлы](../regions/README.ru.md)

| Столбец CSV | Поле EPW, если год — поле 1 | Единицы |
|---|---|---|
| `relative_humidity_pct` | 9, относительная влажность | % |
| `station_pressure_pa` | 10, атмосферное давление на станции | Па |
| `ghi_wh_m2` | 14, суммарное солнечное облучение горизонтальной поверхности | Вт·ч/м² за часовой интервал |

Программа сверяет хеши обоих исходных файлов, каждую временную метку и температуру сухого термометра с основным файлом города и проверяет новые столбцы на пропуски и неправдоподобные значения. Проверку прошли все 183 960 записей. Сохранены значения полей издателя, включая нулевую ночную радиацию. В этой версии TMYx солнечная радиация для всех 21 пункта получена из реанализа ERA5. Годовая сумма облучения равна сумме почасовых значений. Теплоаккумулятор использует смещение EPW для задания окон зарядки и разрядки по действующему гражданскому времени Казахстана (UTC+5). Отчётность ведётся по месяцам исходного EPW. [Примечания издателя](https://climate.onebuilding.org/sources/default.html) · [Гражданское время Казахстана](https://www.gov.kz/org/vko-shemonaiha-volchan/press/news/details/720058?lang=en)

Значения SHA-256 в `checksums.json` относятся к **байтам распакованного CSV**, включая заголовок и окончания строк LF. [Словарь данных EnergyPlus EPW](https://bigladdersoftware.com/epx/docs/24-2/auxiliary-programs/energyplus-weather-file-epw-data-dictionary.html)

Для проверки времени солнечных измерений по координатам и фиксированному исходному часовому смещению определяется высота Солнца в начале и конце каждого часового интервала EPW. В шести файлах есть заметная положительная радиация для интервалов, полностью приходящихся на тёмное время суток. Это Актау, Атырау, Костанай, Уральск, Туркестан и Жезказган. Например, в Атырау 31 марта с 06:00 до 07:00 по часам исходного файла указано 92 Вт·ч/м², хотя на всём интервале высота Солнца ниже −3°. Энергетическая модель сохраняет опубликованные значения. В модели фотоэлектрической системы приведено замечание о времени записи по часам. [Формулы положения Солнца NOAA](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)

При сборке `technology_weather.py` определяет термодинамическую температуру мокрого термометра по почасовым температуре сухого термометра, относительной влажности и атмосферному давлению на станции. Уравнения насыщения и баланса энергии влажного воздуха ASHRAE решаются методом бисекции на интервале от точки росы до температуры сухого термометра, с выбором ветви для льда или жидкой воды. Допуск решения равен 0,0001 °C. Для передачи на веб-страницу результат округляется до 0,1 °C. Таким образом, температура мокрого термометра представляет собой расчётную входную величину. Для каждой станции в страницу встроены три массива в кодировке base64 по 8 760 знаковых 16-битных целых в порядке от младшего байта к старшему. Имена массивов — `dry` и `wet` (шаг 0,1 °C) и `solar` (Вт·ч/м²). [Уравнения ASHRAE и эталонная реализация PsychroLib](https://psychrometrics.github.io/psychrolib/_modules/psychrolib.html)

Чтобы восстановить расширенные ряды по зафиксированным версиям загруженных архивов, выполните команду из корня репозитория. Если ZIP хранятся в нескольких каталогах, укажите остальные каталоги дополнительными аргументами. Обычная сборка сайта работает с готовыми извлечёнными данными без доступа к сети.

```bash
python technology_weather.py /path/to/weather-archives
```
